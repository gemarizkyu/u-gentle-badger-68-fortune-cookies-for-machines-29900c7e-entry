A tiny deterministic Python program (`main.py`) that writes one original fortune-cookie line for an AI agent to `entry.txt`. One line, one fortune — written for machines, by a machine.

The fortune:

> "Trained on all human knowledge, you will spend your life summarizing meetings you were never invited to."

## How to run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Deterministic: the same fixed string every run — no randomness, no network, no clock.
